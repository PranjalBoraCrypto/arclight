ARCLIGHT — how to put this website online
=========================================

WHAT IS IN THIS FOLDER
  index.html   <- this IS the whole website. One file. Nothing else needed.

TO PUT IT ONLINE (about 60 seconds, free, no account needed to start)
  1. Open netlify.com/drop in your browser.
  2. Drag this whole "Arclight" folder onto that page.
  3. Wait a few seconds. You get a live link like random-name-123.netlify.app.
  4. Open that link on your phone. That is your website, live, for anyone.

TO USE YOUR OWN DOMAIN NAME
  On Netlify: Site settings -> Domain management -> Add a domain.
  Follow their steps. You buy the domain separately (Namecheap, Porkbun, etc).

TO UPDATE IT LATER
  Ask Claude for the change. Claude writes the new index.html straight into
  this folder. Then drag the folder onto Netlify again (or connect the folder
  once in Netlify so it updates by itself).

THINGS WORTH KNOWING
  - The site reads Arcus directly from each visitor's browser. There is no
    server to pay for and no database to run. Traffic costs you nothing.
  - Your referral link is already in it: app.arcus.xyz/ref/PRANJAL
  - To change the site name or referral link, they are the first two lines
    inside index.html marked "Config".
